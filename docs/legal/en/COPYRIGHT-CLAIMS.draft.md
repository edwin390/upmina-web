# Copyright Claims Procedure — DRAFT v0.1 (unpublished · working translation · pending legal review)

> Describes the flow the system implements today (COPY-1). It does not assert compliance with any specific legal regime (e.g. DMCA, EU Copyright Directive, Mexican Federal Copyright Law) and sets no deadlines the system does not have. `[PENDING]` = controller's decision.

## 1. What it is and what it is not
- **Copyright claim** (`/copyright`): submitted by the **rights holder** (or representative) when a Community post infringes their work. No account required.
- **Post report** (menu on the post itself, account required): for content that breaches the Community rules (harassment, spam, etc.). It **does not** replace a copyright claim.

## 2. How to submit a claim
Public form: name, email, organisation (optional), relationship to the work, description of the work, link to the post, description of the infringement, evidence links and a truthfulness declaration with signature. Text and links only (no files). Submitting it **does not remove anything automatically**: a moderator reviews it.

## 3. What happens
1. **Review** by a team member.
2. **Removal:** if appropriate, the post is **hidden** (files are not deleted) and the author is emailed with the reason, the reference and a unique appeal link.
3. **Appeal:** the author has **24 hours** from when the notice is confirmed as sent, one appeal per claim (text and links, with a truthfulness declaration).
4. **Resolution:** if the appeal is accepted, the post is restored (only if it is as the removal left it); if rejected, it stays hidden.
5. **Final deletion:** manual, only once the deadline has passed, the notice was sent and no appeal is pending. Files used only by that post are deleted afterwards, asynchronously.
6. **Strikes:** a copyright strike is manual, only after final deletion, and counts together with Community strikes (14 days / 1 month / permanent).
There is no automatic deletion on expiry.

## 4. Data
Claimant and author data are used only to handle the claim and kept as restricted-access evidence (see the Privacy Notice). The claimant should know that claim information may be communicated to the affected author. `[PENDING: decide which claimant data are shared with the author and which are not]`.
