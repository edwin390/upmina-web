---
description: Plan and implement a feature using the AI engineering team
---

Implement the requested feature with this sequence:

1. Tech Lead: inspect and produce a compact plan.
2. Assign frontend/backend specialist only where needed.
3. QA: add/run focused tests.
4. Code Reviewer: inspect the final diff.
5. Security Auditor: inspect security-sensitive changes.
6. Final Auditor: decide READY or NOT READY.

Cost rule: use the least expensive capable model for each step. Do not spawn agents that are unnecessary for this feature.
